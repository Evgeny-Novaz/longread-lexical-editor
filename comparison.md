# Перенос редактора на Lexical

Источник: результат чата «Первая версия редактора текста», актуальная папка `outputs/longread-editor` в его рабочем пространстве. Исходный чат, файлы и репозиторий не изменялись. Новая версия создана отдельно.

Основа: Lexical 0.52.0 и официальный [Lexical Playground](https://playground.lexical.dev/). Код примеров взят из [facebook/lexical, commit 4f385cd](https://github.com/facebook/lexical/tree/4f385cd03afae05fc72d114e3ebea0c7fcfa1040/packages/lexical-playground). Лицензия MIT включена в исходники.

Под «есть в библиотеке» здесь понимаются готовые пакеты Lexical и реализации официального Playground. Возможности, требующие разработки нового типа блока или отдельной системы поверх редактора, не добавлены. Lexical расширяем: отсутствие готовой реализации не означает техническую невозможность разработать её в будущем.

## Реализовано

| Функция исходника | Результат и основа |
| --- | --- |
| Редактирование заголовка и текста | Отдельное поле названия; содержание — состояние Lexical |
| Обычный текст, заголовки и подзаголовки | ParagraphNode, HeadingNode, RichTextExtension |
| Жирный, курсив, подчёркивание, зачёркивание | FORMAT_TEXT_COMMAND |
| Нижний и верхний индексы, строчный код | Форматы subscript, superscript, code |
| Цвет текста и фона выделения | @lexical/selection, DropdownColorPicker |
| Сброс форматирования | clearFormatting из Playground |
| Выравнивание и отступы | FORMAT_ELEMENT_COMMAND, команды отступов |
| Маркированные и нумерованные списки | @lexical/list |
| Цитаты и блоки кода | QuoteNode, @lexical/code; подсветка синтаксиса |
| Ссылки, изменение адреса и удаление ссылки | @lexical/link, FloatingLinkEditorPlugin |
| Панель форматирования выделения | FloatingTextFormatToolbarPlugin; на узком экране используется основная панель |
| Добавление блоков | Меню «Добавить», меню по `/`, «+» у блока на широком экране |
| Изображение из файла, вставка из буфера, перетаскивание | ImagesExtension, DragDropPasteExtension |
| Изменение размера изображения, подпись | ImageComponent, ImageResizer, вложенный редактор подписи |
| Разделитель | HorizontalRuleExtension |
| Таблицы | @lexical/table, изменение размеров, действия с ячейками, строками и столбцами |
| 2, 3 или 4 колонки | LayoutExtension; форматирование внутри колонок |
| Аккордеон | CollapsibleExtension; редактирование заголовка и содержимого, раскрытие и сворачивание |
| Формулы LaTeX | EquationsExtension + KaTeX; строчные и отдельные формулы, изменение существующей формулы |
| Видео | Частично: готовое встраивание YouTube по ссылке |
| Комментарии к выделению | MarkNode + CommentPlugin; обсуждения, ответы, удаление сообщений или обсуждения |
| Перемещение блоков | DraggableBlockPlugin из Playground; ручка на экранах шире 640 px |
| Отмена и повтор | HistoryExtension |
| Предпросмотр без редактирования | editor.setEditable(false), скрытие инструментов |
| Автосохранение | Сериализация состояния Lexical в отдельную IndexedDB; название и обсуждения — отдельные ключи localStorage |

Сохранение локальное для данного адреса сайта и браузера. На другом устройстве, в другом браузере или по другому адресу будет отдельный черновик. Это прикладная обвязка сериализации Lexical, без серверного хранения и совместного редактирования.

## Не реализовано — нет готового аналога в официальном Playground

1. **Инфоблок с фоном и эмодзи.** В Playground нет полного аналога исходного блока с этими настройками. Обычная цитата и цвет фона выделенного текста доступны, но не заменяют такой блок.
2. **Синхронизируемые блоки между статьями:** создание общего блока, копирование его экземпляров, обновление всех экземпляров, отключение связи, список статей использования. Yjs в Lexical предназначен для совместного состояния документа; это не готовая система общих блоков хендбука.
3. **Именованные якоря:** создание цели, переименование с обновлением входящих ссылок, удаление цели с преобразованием ссылок в текст. Обычные ссылки поддерживаются.
4. **Файловые вложения** с карточкой и скачиванием.
5. **Аудиовложения** и аудиоплеер.
6. **Загрузка своего видео и произвольный видеоплеер.** Доступен только готовый блок YouTube.
7. **Редактирование уже отправленных комментариев и ответов, отметка «Изменён», отмена удаления комментария.** Готовый CommentPlugin поддерживает добавление, ответы и удаление.
8. **Режим LaTeX «Текст с формулами»**, который разбирает целый текстовый блок с `$...$` и `$$...$$`. Доступны отдельные строчные и блочные формулы среди обычного текста.
9. **Особое поведение пустых колонок:** удаление пустой колонки по Backspace с перераспределением ширины и разворачиванием последней колонки в обычный текст. У LayoutExtension есть собственная обработка границ; сценарий исходника целиком не воспроизводился.
10. **Особые действия изображения:** три отдельные кнопки выравнивания изображения вместе с подписью и скрытие пустой подписи по Backspace. В Playground используются его собственные средства размера и подписи.
11. **Точный сценарий перемещения блоков с клавиатуры Alt + ↑ / ↓.** Перенесена готовая ручка перетаскивания Playground; собственная клавиатурная механика исходника не добавлялась.

## Функции хендбука за пределами редактора

Дерево разделов, тем и статей; создание, удаление и перенос статей; поиск по хендбуку; права «Кто может просматривать»; статус публикации и история снимков каждой статьи не входят в библиотеку текстового редактора. В этой отдельной версии их нет. Надпись «Черновик» обозначает локальный документ; она не является действием публикации.

В Playground имеется пример версий на базе совместного Yjs-документа, но он требует отдельной инфраструктуры и не является готовой локальной историей статей из исходника. Здесь доступна обычная отмена и повтор действий.

Не переносились как требования актуального интерфейса скрытые прежние пункты JSON/PDF: в README исходной версии указано, что они были убраны из меню по запросу пользователя. Самостоятельный экспорт в PDF эта версия не добавляет.

## Проверка

Проверено в браузере: загрузка интерфейса, жирное начертание, вставка таблицы, двух колонок, аккордеона и формулы, отмена вставок, сохранение и восстановление форматированного текста после перезагрузки, создание комментария к выделению, ответ, восстановление обсуждения после перезагрузки, удаление обсуждения, переключение предпросмотра. Также проверены вставка и загрузка тестового изображения из Playground. Производственная сборка Vite проходит.

Прямое открытие локального комплекта через file:// не проверено: встроенный браузер среды разрешает только HTTP/HTTPS. Комплект проверен через локальный HTTP-сервер.

Загрузка изображения, изменение размера, системная вставка изображения, перетаскивание блоков и воспроизведение YouTube не проверялись сквозным тестом с пользовательскими файлами/буфером. Использованы готовые реализации Playground; это ограничение проверки, а не отсутствие функций.
