# Редактор текста на Lexical

Отдельная версия по результату чата «Первая версия редактора текста». Исходный проект не изменён.

## Открыть редактор

[Публичная версия редактора](https://evgeny-novaz.github.io/longread-lexical-editor/)

GitHub Pages публикует готовую сборку из ветки `gh-pages`. После изменения исходников сборку в этой ветке нужно обновить.

## Запуск исходников

Требуется Node.js 20.19+ и pnpm. Выполните `pnpm install`, затем `pnpm dev`. Откройте адрес из терминала.

`pnpm build` создаёт статическую сборку в `dist/`. Для просмотра: `python3 -m http.server 4173 --directory dist --bind 127.0.0.1`, затем http://127.0.0.1:4173/ . Не открывайте index.html через file://: для модулей нужен HTTP.

## Реализация

Lexical 0.52.0, React, TypeScript, Vite. Основа UI и расширенных блоков — официальный Lexical Playground (MIT), upstream commit 4f385cd03afae05fc72d114e3ebea0c7fcfa1040. Лицензия — LICENSE.

`src/Workbench.tsx` содержит оболочку, поле названия, переключение режима просмотра и локальное сохранение. Состояние редактора хранится в IndexedDB `cu-lexical-workbench-v1`; название и обсуждения — в localStorage с префиксом `cu-lexical-`. Хранилища исходного прототипа не используются.

`src/App.tsx`, `src/Editor.tsx` соединяют расширения и плагины Lexical; `src/plugins/` и `src/nodes/` содержат реализации Playground. Меню ограничены функциями перенесённого редактора. Сохранение и комментарии локальные, без сервера и совместного режима.

Подробная таблица функций и исключений: `comparison.md` и `public/comparison.html`. Проверка происхождения функций и описание прикладной обвязки: `audit.md`.

`pnpm build:offline` создаёт классическую сборку без ES-модулей в `offline/`, рассчитанную на открытие index.html напрямую в браузере. Прямой запуск через file:// не удалось проверить: встроенный браузер среды разрешает только HTTP/HTTPS. Локальный комплект проверен через HTTP.
